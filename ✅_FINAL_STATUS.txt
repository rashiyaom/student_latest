1. TRANSFER TO JETSON:
   scp -r c:\Users\Administrator\Desktop\student_latest ubuntu@<jetson-ip>:~/evileye

2. SSH INTO JETSON:
   ssh ubuntu@<jetson-ip>

3. INSTALL DEPENDENCIES:
   cd ~/evileye
   pip3 install opencv-python numpy flask

4. PREPARE TENSORRT ENGINE:
   • Option A: Copy pre-built engine
     cp yolov8n.engine ~/evileye/
   
   • Option B: Build from ONNX
     yolo export model=yolov8n.pt format=onnx imgsz=320
     /usr/src/tensorrt/bin/trtexec --onnx=yolov8n.onnx \
       --saveEngine=yolov8n.engine --half

5. RUN THE SYSTEM (2 TERMINALS):
   
   Terminal 1 - Tracking Pipeline:
     python3 single_student_main.py
   
   Terminal 2 - Dashboard Server:
     python3 server.py

6. ACCESS DASHBOARD:
   • Local: http://localhost:5000
   • Remote: http://<jetson-ip>:5000
   • Example: http://192.168.1.100:5000

Common Problems & Solutions:

  Q: "TensorRT engine not found"
  A: Copy yolov8n.engine to project root directory

  Q: "Cannot open webcam"
  A: Check with: ls /dev/video*
     Fix permissions: sudo usermod -aG video $(whoami)

  Q: "Face cascade not found"
  A: Install with: sudo apt-get install libopencv-dev

  Q: "Flask not installed"
  A: Install with: pip3 install flask

  Q: "Dashboard shows IDLE"
  A: Check: ps aux | grep python3
     Verify: cat outputs/state.json

  Q: "Low FPS (< 10)"
  A: Check temp: sudo tegrastats
     Lower INPUT_SIZE to 256
     Reduce CONF_THRESH to 0.3
